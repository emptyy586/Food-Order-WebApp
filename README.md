Food Order WebApp
Food Order WebApp là một ứng dụng web đặt đồ ăn trực tuyến được xây dựng nhằm mô phỏng hệ thống gọi món trong thực tế. Dự án giúp người dùng dễ dàng duyệt danh sách món ăn, thêm vào giỏ hàng và thực hiện đặt hàng một cách nhanh chóng, tiện lợi.
Ứng dụng được thiết kế với giao diện thân thiện, dễ sử dụng và phù hợp cho việc học tập cũng như phát triển các hệ thống thương mại điện tử nhỏ.
- Mục tiêu dự án
Xây dựng một hệ thống đặt đồ ăn cơ bản
Áp dụng kiến thức về Frontend + Backend + Database
Tạo nền tảng để phát triển các tính năng nâng cao như AI gợi ý món ăn
- Tính năng chính
Hiển thị danh sách món ăn theo danh mục (cơm, mì, trà sữa, nước uống,...)
Thêm / xoá / cập nhật món trong giỏ hàng
Tính tổng tiền tự động
Trang thanh toán với form nhập thông tin người dùng
Trang quản trị (Admin) quản lý món ăn
- Công nghệ sử dụng
Frontend: HTML, CSS, JavaScript
Backend: (có thể mở rộng Flask / Node.js)
Database: (MySQL / CSV / JSON tùy phiên bản)
- Định hướng phát triển
Tích hợp AI Recommendation (gợi ý món ăn cá nhân hóa)
Kết nối cơ sở dữ liệu SQL hoàn chỉnh
Nâng cấp UI/UX chuyên nghiệp hơn
Triển khai online (hosting)
